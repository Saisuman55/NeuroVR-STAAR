# NeuroVR Research References

This directory records the research and technical sources used to design NeuroVR. It keeps architectural choices, medical-imaging assumptions, evaluation methods, and future visualization decisions traceable for the final academic report.

## How to add a reference

1. Prefer the original paper, a peer-reviewed venue, a recognized preprint server, or official project documentation.
2. Verify that the source exists and record its authors, title, year, venue, DOI or reliable URL.
3. Summarize only claims supported by the source; do not copy implementation code.
4. Label the source as foundational, methodology, comparison, background, or directly relevant to NeuroVR.
5. Record the date of access when a source is likely to change, especially documentation.

All relevant sources must be cited in the final project report. Experimental results in the report must come from NeuroVR's own controlled experiments. Expected results, published results, and target metrics must never be presented as achieved NeuroVR results. External papers are references for rationale and comparison, not evidence of this project's performance.

No papers are downloaded automatically by this project. This index stores bibliographic information and links only.
