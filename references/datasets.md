# NeuroVR Dataset Provenance and Demonstration Data

This file records dataset provenance separately from model results. No dataset is considered ready until its files are present locally and its manifest has been generated by NeuroVR.

## Brain Tumor MRI Dataset (2D Classification)

- **Source:** Kaggle, dataset reference `dsv/2645886`
- **URL:** https://www.kaggle.com/dsv/2645886
- **Modalities:** 2D MRI axial brain scans in JPG/JPEG/PNG form
- **Classes:** `glioma`, `meningioma`, `notumor`, `pituitary`
- **Access / License:** Follow the dataset's Kaggle access and license terms. Kaggle API credentials required for acquisition.
- **Local Status:** Present on disk under `data/classification/`.
- **Actual Local Statistics (Verified by NeuroVR):**
  - Total Images: 7,200 valid images (0 invalid)
  - Training Split: 5,600 images (1,400 per class)
  - Testing Split: 1,600 images (400 per class)
  - Class Distribution: perfectly balanced (1,800 images per class across training + testing)
- **NeuroVR Use:** Training and evaluation for 2D brain tumor classification experiments using EfficientNet-B4.

## BraTS Benchmark Dataset (3D Segmentation)

- **Source:** Brain Tumor Segmentation (BraTS) Challenge / CBICA, Perelman School of Medicine, University of Pennsylvania
- **URL:** https://www.med.upenn.edu/cbica/brats2021/
- **Access Route:** Registered challenge participant portal / Synapse repository (e.g. Synapse syn25829067 / syn51156910).
- **Modalities:** Multi-parametric 3D MRI:
  - T1-weighted (T1)
  - T1-weighted contrast-enhanced (T1ce / T1Gd)
  - T2-weighted (T2)
  - Fluid Attenuated Inversion Recovery (FLAIR)
  - Segmentation ground truth (seg) with tumor sub-region labels:
    - Label 1: Necrotic and non-enhancing tumor core (NCR/NET)
    - Label 2: Peritumoral edema (ED)
    - Label 4: GD-enhancing tumor (ET)
- **Access / License Terms:** Formal challenge registration, user agreement acceptance, non-commercial research use only, strictly prohibiting re-distribution or de-anonymization. NeuroVR never bypasses registration, authentication, or access controls.
- **Local Status:** Not imported. Manifest `data/segmentation/brats_manifest.json` correctly reports 0 subjects. Pipeline and importer (`scripts/import_brats_dataset.py`) stand ready for import when official authorization is granted.

## Statistics Policy

- **Dataset-reported statistics** are facts published by a dataset provider or paper and must be labeled as such.
- **Statistics measured by NeuroVR** are computed from local files and manifests.
- Neither category may be substituted for the other, and neither establishes clinical diagnostic validity.
- The web interface explicitly distinguishes between volume loading status and segmentation model availability: volume loading does not imply tumor detection or completed segmentation.
